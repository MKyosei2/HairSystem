# Novelty01 Formal Orchestration Revision 70.32

70.32 is an orchestration-only revision. It intentionally leaves the already-reviewed 70.31 measurement contract unchanged.

## Why 70.32 exists

The 70.31 measurement implementation itself passed repository CI, but the complete local thesis run was being launched through a large ad-hoc PowerShell block pasted into an interactive Windows PowerShell 5.1 console. Two launcher-only failures were observed:

1. the localized Japanese `powercfg` display name became mojibake and an external launcher falsely rejected a valid High Performance power scheme even though the authoritative GUID was correct; and
2. a later generated launcher contained a PowerShell parser error before any formal stage could start.

Those failures were outside the 70.31 Viewer/matrix/report/FinalGate implementation, but they made the end-to-end thesis workflow unreliable.

## 70.32 policy

`tools/final_stage/Run_Thesis_B0_P_Formal_7032_All.ps1` is now the repository-owned entry point for a complete thesis run.

It:

- is parsed in CI by Windows PowerShell tooling before it can reach `main`;
- has a `-ValidateOnly` path that exercises the inherited 70.31 runtime transformation under Windows PowerShell 5.1 without starting a formal session;
- validates High Performance by the stable scheme GUID `8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c`, never by a localized display name;
- records the canonical ASCII power-plan GUID into `hardware_profile.json` before Asset freezes the profile;
- creates a new isolated session instead of reusing failed sessions;
- runs the exact stage sequence Prepare -> Asset -> Pilot -> Quality -> Performance -> Determinism -> Soak -> Report -> VerifyBranches -> FinalGate -> Archive;
- verifies cumulative 70.31 Window Guard evidence after Pilot, Quality, Performance, Determinism, and Soak; and
- requires `FORMAL_COMPLETE_VALID`, FinalGate PASS, 90/90 Window Guard PASS records, and a matching Archive SHA-256 before declaring completion.

## Measurement semantics intentionally unchanged

70.32 does not change the scientific comparison. The evidence generated by this orchestrator remains formal revision 70.31:

- Pilot: 10 runs
- Quality: 36 runs
- Performance: 36 runs
- Determinism: 4 runs
- Soak: 4 runs
- Total: 90 runs = 45 B0 + 45 P
- Smoke: excluded
- Qualification: detached and excluded
- fixed-client Window Guard: `fixed-client-window-guard-v1`
- native Viewer ExitCode 92: still fatal
- performance/quality/measured thermal-clock/determinism threshold misses: recorded outcomes, not converted into harness failures

This separation is deliberate: 70.32 fixes only orchestration reliability and does not alter the thesis measurement conditions or result policy.
